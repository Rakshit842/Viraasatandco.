# Viraasat & Co. landing page (React + Vite + Tailwind)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

- `src/components/Logo.jsx` is the vector logo. Use `<Logo size={42} />` on cream and `<Logo tone="dark" />` on charcoal.
- Brand colours live in `tailwind.config.js` (cream, terra, sage, char, espresso).
- The Kapoor family story and the Instagram link are placeholder content. The create-vault form is a preview and sends nothing.
